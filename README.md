# 🐾 Pet Adoption UI (Flutter)

A clean, modern, and responsive **Flutter Pet Adoption UI** built using **Material 3**, featuring a smooth browsing experience, favorites system, hero animations, dark mode, and beautifully organized screens.

## ✨ Features

- 🏠 **Home Screen**
  - Search pets by name or breed
  - Filter by type (All, Dogs, Cats)
  - Smooth grid layout with hero animations
- ❤️ **Favorites**
  - Mark/unmark pets
  - Favorites badge in the bottom navigation bar
- 👤 **Profile**
  - Dark/Light mode switch
- 🐶 **Pet Details**
  - Large hero image header
  - Glass/frosted title overlay
  - Breed, age, gender, distance info
  - “Adopt Me” action
- 🎨 **UI / UX**
  - Material 3 design
  - Responsive layout
  - Clean, minimal component structure

---

Requirements
Flutter 3.16+
Dart 3+
Android / iOS / Web supported
